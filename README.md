Project Overview
This project was completed as part of my Swynex Internship and focused on analyzing customer personality and
purchasing behavior using the Customer Personality Analysis dataset.
The goal was to transform raw customer data into meaningful insights that could help a business understand its
customers, identify spending patterns, evaluate marketing campaign performance, and make more informed decisions.
1. Task 1 – Data Cleaning: Prepared the dataset using Excel Power Query.
2. Task 2 – Exploratory Data Analysis (EDA): Used SQL Server to explore the data and calculate metrics, then used
Excel charts to visualize findings and prepare a mini-report.
3. Task 3 – Interactive Dashboard: Built an interactive Excel dashboard to present the analysis in a clear and
accessible way.
The workflow covered the main stages of a data analysis project, from preparing raw data to communicating findings
through visualizations.
